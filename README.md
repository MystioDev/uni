# 🎓 Egyetemi Projektek és Vizsgák (uni)

Üdvözöllek az **Egyetemi Projektek és Vizsgák** repositoryban! Ez a mappaszerkezet a második féléves programozási kurzusok anyagait és vizsgafeladatait tartalmazza.

---

## 📂 Repository Mappaszerkezete

Az alábbi könyvtárfa mutatja a repository főbb részeit:

```text
uni/
├── II. Félév/                               # Második féléves kurzusok és vizsgák
│   └── Programozás/                         # Programozás tárgyak
│       └── C#/                              # C# nyelvű projektek
│           └── 2026_05_28_vizsga/           # Vizsga dátuma: 2026-05-28
│               ├── DOCS.md                  # Vizsga dokumentáció
│               ├── TASK.md                  # Vizsga feladatleírás (a feladatlap képére hivatkozik)
│               ├── base_code/               # A vizsga kezdetekor kapott sablonkód
│               │   └── Nagyzh_004_BaseCode/ # C# Konzolos Projekt (befejezetlen sablonok)
│               └── solution/                # A vizsga teljes, működő megoldása
│                   └── Nagyzh_004_BaseCode/ # C# Konzolos Projekt (teljesen implementálva)
│                       ├── Interfaces/      # Projekt interfészek (IExhibition.cs)
│                       ├── Models/          # Core osztályok (Artifact, Donations, Exhibition stb.)
│                       ├── Program.cs       # Fő futtató osztály preprocesszor flag-ekkel (PART1 - PART11)
│                       └── *.json           # Teszteléshez használt bemeneti és várt kimeneti JSON fájlok
└── assets/                                  # Grafikus erőforrások, képernyőképek, feladatlapok
    └── 2026_05_28_prog2_feladat.png         # Az eredeti vizsga feladatlap képe
```
